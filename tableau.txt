# c. Yearly Sales Comparison

Adult dataset has NO sales/year.

So examiner usually expects:

```text id="2v8m5r"
year-wise count/income comparison
```

If no year column:
Use:

```text id="9q4m1x"
age distribution instead
```

OR skip politely.

If dataset contains year/date:

* YEAR(Date) → Columns
* Number of Records → Rows
* Line chart

# g. Income Class Based on Workclass

(Government vs Other)

---

# Step 1 — Create Calculated Field

Name:

```text id="3n7q1v"
WorkClassGroup
```

Formula:

```text id="6x2m5q"
IF CONTAINS([workclass],"gov")
THEN "Government"
ELSE "Other"
END
```
